Attendance Calculator 🚀
Attendance Calculator is a sleek and intuitive web app designed to help students and professionals alike calculate, project, and strategize their attendance. Whether you're tracking lectures, planning future attendance, or simulating skipped sessions, this tool has you covered!

Features ✨
Real-time Calculation:
Instantly compute your current attendance percentage with precision.
Example: Attended vs. Conducted lectures → 📊 Instant Results!

Future Projections:
Estimate your projected attendance from today until a given deadline.
Plan ahead and stay in control! 🔮

Threshold Analysis:
Determine how many extra lectures you need to attend—or skip—to hit target percentages (50%, 60%, 70%, 75%).
Your attendance game, leveled up! 🎯

Custom Simulation:
Experiment with simulating skipped lectures to see the impact on your overall attendance.
Because sometimes, planning is everything. 🔄

User-Friendly Interface:
Built with Flask, HTML, CSS, and Python's powerful libraries.
Smooth, responsive, and built for performance. 💻🔥

Technologies Used 🛠️
Python: Core programming language for backend calculations.
Flask: Lightweight web framework for rapid development.
HTML & CSS: Crafting a clean and interactive user interface.
Datetime & Math Libraries: Ensuring accurate and efficient attendance computations.
